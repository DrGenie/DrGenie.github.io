- "All citations as BibTeX" link at the top of Papers.
- Skip-to-content link for keyboard and screen-reader users.
- Citations set to 1009 in the metrics file and on the About page.
- Site-wide link preview card redrawn in the current design.

Reverted from the last version: the self-hosted font (back to the same
Google-served Inter as before), the homepage thumbnails and at-a-glance
line, the "Start here" block on Papers, and the visual grid on Writing.
